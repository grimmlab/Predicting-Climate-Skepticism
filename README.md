Machine learning predicts climate skepticism and identifies individual driving features with explainable artificial intelligence
===============================================================================================================================
Climate Skepticism shapes public opinion and has increasing influence in political debates. Numerous studies have examined features associated with Climate Skepticism. Such features are often analyzed in isolation, overlooking which features actually have the highest predictive power. To address this research gap, we use explainable artificial intelligence to quantify the extent to which the different Climate Skepticism dimensions (\textbf{Awareness}, \textbf{Belief}, \textbf{Human Responsibility}) are predictable and to rank individual features by importance. For this, we leveraged predictions generated by the machine learning method eXtreme Gradient Boosting, a decision tree-based ensemble learner. This model was trained on 15,000 samples that included diverse information about individuals ranging from personal characteristics to political opinion. A subsequent SHapley Additive exPlanations analysis provided a detailed overview of features supporting climate change beliefs. We find notable differences in explained variance for the outcomes.
